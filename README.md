# HarmonyOS API Lab

鸿蒙官方 API 实测代码。每个 API 一个独立工程，配套公众号合集《鸿蒙 API 避坑录》。

跑的时候遇到的问题不藏着，报错原文和改法都留在 `docs/` 里。

## 目录

| 目录 | 内容 |
|---|---|
| `apps/` | 每个 API 实践一个独立工程，互不依赖 |
| `docs/` | 对应项目的报错记录 |

项目目录按实际用途命名，比如 `mf_api`、`mf_locate`，不用 demo、sample 这类名字。

## 怎么跑

1. 用 DevEco Studio 打开 `apps/` 下的项目目录
2. 真机调试要先配签名，模拟器可以跳过
3. 同步依赖后直接运行

每个项目互相独立，只关心某一个 API 的话，单独打开对应目录就行。

## 关于报错记录

`docs/` 下每个项目记录遇到的问题、报错原文和改法。想搜某个报错，直接搜这个仓库比翻论坛快。
